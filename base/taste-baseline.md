# taste-baseline (fallback floor)

A short, original anti-slop floor for when no richer base taste skill is installed.
This is deliberately minimal. If you have a full design skill, that takes priority
and this file is ignored.

## Defaults
- One accent color per page. Neutrals stay in one temperature (all warm or all cool).
- No AI-purple or blue-glow gradients as a default. Reach for a real palette.
- Sans display by default. Serif only when the brand genuinely earns it.
- Grid over flexbox percentage math. `min-h-[100dvh]` for full-height, never `h-screen`.
- Real images over div-based fake screenshots. A text-plus-gradient hero is a placeholder.
- One corner-radius scale, one theme (light or dark) for the whole page.

## Anti-tells (banned as defaults)
- Centered hero over a dark mesh with three equal feature cards.
- An eyebrow label above every section.
- Beige-plus-brass-plus-espresso "premium consumer" palette.
- Inter plus slate-900 as the reflexive type choice.
- Infinite micro-animations on every element.

## Copy
- No em dashes. Use commas, colons, or parentheses.
- Headlines under 8 words. Hero subtext under 20 words.
- One CTA intent per page, one label for it everywhere.

The point of taste-engine is to grow past these generic defaults into YOUR
specific aesthetic, captured per project.
