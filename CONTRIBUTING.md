# Contributing to taste-engine

Thanks for helping. Small, focused PRs get merged fastest.

## Setup

```bash
git clone https://github.com/shauryalowkeygotaura/taste-engine
cd taste-engine
```

## Before you open a PR

```bash
bash -n install.sh
```

- One change per PR. Say what it fixes and how you tested it.
- Keep the existing code style. No new dependencies without a reason in the PR description.
- New behaviour comes with a test where the repo has tests.

## Where to start

Issues labelled [good first issue](https://github.com/shauryalowkeygotaura/taste-engine/labels/good%20first%20issue) are scoped for a first PR. Questions go in [Discussions](https://github.com/shauryalowkeygotaura/taste-engine/discussions).
